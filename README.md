## 🧠 Overview

This is the **frontend** repository of HarmonyHub, a mental health platform for pre-marital psychological counseling.

Built with **React (JavaScript)**, styled using **Tailwind CSS** and **shadcn/ui** component library, it provides a clean and responsive user interface for:

- Booking counseling appointments with experts
- Taking personalized quizzes
- Receiving expert recommendations
- Joining virtual counseling sessions
- Making payments securely
